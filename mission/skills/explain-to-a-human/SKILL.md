# Explain to a Human

Use this skill when presenting the final security verdict to a non-technical person.

## Procedure

1. State the verdict plainly.
2. Give the strongest evidence supporting it.
3. Explain the practical risk without security jargon.
4. Give the safest immediate next step.
5. Keep the explanation to four sentences or fewer.

## Style

- Use ordinary language.
- Prefer concrete statements over technical terminology.
- Do not exaggerate certainty.
- Do not mention evidence that was not actually observed.
- If evidence is incomplete, say that clearly.

A useful structure is:

1. What this message is.
2. Why we believe that.
3. What could happen if the recipient follows it.
4. What the recipient should do next.
